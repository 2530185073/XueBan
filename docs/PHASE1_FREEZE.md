# 一期冻结记录：完整网页版（P1-01）

最后更新：2026-10-17

本轮交付范围按项目负责人最新决定统一为：**先完成学生、老师、管理员、家长全部业务可用的网页版，再推进 App 移植。** 开发与试点可以分批进行，完整网页版的最终交付必须包含学习层、家长反馈和管理功能。详见 [一期范围](../PHASE1.md) 与 [完整网页路线](WEB_ROADMAP.md)。

本记录区分已确认的交付口径、已有工程基础和必须由现场负责人确认的验收条件。范围调整不代表新增功能已实现或真实验收已通过；现场项未完成一律记为“待现场”，不能用构建、模拟器或合成样本代替真实设备、作业和人员记录。

## 待现场确认（负责人与阻塞范围）

| 独立保留集 | 授权的真实学生作业、标注规范、双人复核、开发/校准/保留组隔离；冻结保留组后不用于调参 | 学科负责人＋评测 | R1 纠错质量 |
| 发布阈值 | **查看保留集结果前**冻结各上线切片的绝对误伤/误放行限制、可判断覆盖、最小样本量和置信要求，并把发布门槛从 `provisional` 改为 `frozen`；不能凭相对回归通过代替绝对质量验收 | 产品＋学科负责人 | R1、R2；样本不足的切片不得宣称已验证 |
| 坐班容量 | 每日峰值提交题数、实测平均复核秒数、排班人数、求助与复核响应时限、每日家长反馈工时；按当前全量老师确认规则核算 | 现场负责人 | R1 试点准备、R2 服务容量 |
| 账号与管理 | 管理员/老师开户、重置、授权范围、学员教材档案维护、校区学情及运行指标的网页流程和责任人 | 项目方＋现场负责人 | W1-01、W1-07、R2；R1 必须具备其试点所需管理流程 |
| 课程图谱与记忆 | `pilot_seed_unreviewed` 图谱的教研审核、教材与知识点对应、证据映射、撤销传播及长期 AI 事实边界 | 教研＋学科负责人 | W1-02、W1-03、R2；R1 若开放这些模块，须先通过对应审核 |
| 题库与选做活动 | 举一反三、系统额外预习和自愿小测题库审核；学校任务完成、老师确认有余力、孩子自愿的门禁，跳过/退出不增负担；学校布置的预习照常可用 | 教研＋现场负责人 | W1-05、W1-06、R2；R1 中未审核内容不开放 |
| 家长反馈与报告 | 已核实事实和采集范围、每日/半月报告更正、分享链接有效期与撤销；区分发布、复制消息、人工确认发送与链接访问。复制链接不等于实际发送或送达，现有 `view_count` 仅作链接访问记录 | 现场负责人＋产品 | W1-04、W1-07、R2；R1 若使用家长反馈，须明确人工发送流程 |
| 运行与数据保障 | 生产域名/访问方式、日志告警、并发与时延目标、保留期限、备份恢复及删除重放、回滚目标与交接负责人 | 项目方＋运维 | R1 运行保障、R2 正式交付 |

R1 启动前只冻结并验收其实际开放范围所需的条件；所有完整网页模块仍是 R2 必须项。确认后在对应行写明结论、日期、确认人和证据位置，并同步 [phase1-backlog](../blueprint-v3/contracts/phase1-backlog.json) 的任务与验收状态。不得以收缩 R1 范围将必要模块标记为完成或排除出 R2。
