五任务各自轮询观察耗时为7.11、4.06、2.03、3.05、5.07秒，含排队与轮询误差；不是供应商推理基准、P95或整页作业耗时。费用仍待账单核对。此题参与开发调试，不能用作独立保留集。

## 实调中发现并修复的问题

1. PNG在读取EXIF后调用Pillow verify触发500；改为独立fresh open解码/校验，补JPEG/PNG/WebP回归。
2. v1/v2把合成印刷说明、无法确认作者或未展示步骤泛化成不能判断；模型任务指令原来与证据都放在user，现以服务端固定system规则与user图片/JSON分离，允许候选对错，未知步骤不补造。
3. v3已判出原错题并给出提示，但再检因Question格式前缀、旧新答案差异过度降级；v4统一明确字段标签，仅用当前作答核验。保留负号、指数、括号和数字间隔，不用模糊数学等价强行绑定；有实质歧义仍降级。
4. 交叉审查修复慢上传跨await持数据库锁、错拍别题绑定、提示重复调用及模型已返回后落库失败丢用量证据。
5. 安卓真实提示后订正发现请求枚举与契约不符：本地hint_used不能直接作为reported_help发送；客户端改为保守unknown，已真实记录的提示由服务端父作答继承，旧草稿也兼容恢复。

所有失败记录和原始调用审计保留于本机私有runtime，没有清除失败后仅保留成功。公开材料只包含合成题及匿名摘要，不提交用户手写照片、完整模型响应、签名材料或密钥。
