## 解释边界

- 所有模型输出仍是 `candidate`，没有写入学生“已改对”“已掌握”或任何生产作业状态。
- 原图与订正图是不同图；再检查没有收到旧错误结论或预期答案。同一底座换角色不等于独立模型验证。
- 一级提示本次人工阅读未发现最终表达式；模型自报 `exposes_answer=false` 不能替代提示泄题评测。
- 向量经稳定L2归一化，查询/语料使用同一模型、维度与指令配置。该样例余弦值不是召回准确率、知识掌握度或置信度；索引数据库未接入。
- 图像来自 [合成夹具](../../../evals/correction/fixtures/ark-smoke/README.md)。真实中文手写、整页切题、几何、不同解法、模糊图及错误订正尚需授权样本评测。
- C0/R1/R2仍未通过；本轮没有新发布一个可联网纠错的安卓APK。

## 复验入口

离线测试不需要密钥：

```sh
services/backend/.venv/bin/python -m pytest services/backend/tests -q
```

显式付费的合成图片复验（报告必须为仓库外的新路径，私有配置须0600）：

```sh
services/backend/.venv/bin/python services/backend/scripts/ark_smoke.py \
  --live --env-file /secure/path/ark.env --output /tmp/new-ark-run.json
```

私有配置包含 `ARK_BASE_URL`、`ARK_MODEL`、`ARK_API_KEY`，样例见 [后端配置](../../../services/backend/.env.example)。脚本不执行配置文件里的shell代码，每次最多五个请求且不自动重试；付费调用前预检并创建报告，每步保存，写盘失败停止下一次调用。检查点是诊断文件，不是事务性生产账本；生产Worker仍需任务持久化、硬执行期限与用量预算。
