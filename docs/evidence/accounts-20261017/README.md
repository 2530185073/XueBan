# 永久学员账号与身份连续性验收

日期：2026-10-17。范围：本机开发环境的个人账号密码、管理端开户/重置、稳定学员归属与迁移；不是知识图谱或正式托管点验收。

## 实际运行

- 本机 FastAPI + PostgreSQL 17，升级至 `0004_password_accounts`。模型Worker继续使用原运行环境，本轮没有调用模型。
- 真实Chrome浏览器操作普通登录、初始改密、管理员页面、历史、重置和退出；测试读取本机0600私有凭据，未把密码传入工具输出、截图、日志或Git。
- 管理员没有任何学生作业授权，只持有显式校区管理授权；通过网页创建另一名合成验收学员。第二名学员读取原学员作业返回404，访问管理接口返回403。
- 重置后旧学员会话返回401；新的临时密码登录仅能进入改密流程，业务API返回403。更换密码后读取原学员7份作业，退出后原token返回401。
- 同一浏览器刷新恢复账号与历史。1440宽度管理/历史页、390宽度登录页截图已人工查看；登录页无横向溢出，无浏览器page error。窄屏截图在禁用进场动画后拍摄，避免将动画中间帧误作实际低对比度。

真实浏览器步骤见 [browser-result.json](browser-result.json)。截图保留本机被忽略目录，不公开学生历史页面。

在迁移前保存本机基线，迁移和全部账号验收完成后再查询数据库，逐项比对原学员的作业ID、作答ID及父作答ID、图片ID。比对结果见 [migration-result.json](migration-result.json)：

| 对象 | 数量 | 结果 |
|---|---:|---|
| 固定学员ID | 1 | 同一学员，没有新建替代身份 |
| 作业ID | 7 | 全部一致 |
| 作答ID及订正父链 | 38 | 全部一致 |
| 图片资产ID | 9 | 全部一致 |

以上证明这些既有记录与关系在本次账号操作中保留，不代表备份恢复或所有生产迁移已经验证。

## 后续边界

账号只是长期学习档案的入口，稳定学员ID和纠错证据才是图谱与个人AI的归属依据。当前没有运行中的个人知识状态、长期AI记忆和家长报告模块，不把AI候选错误当作已证实薄弱点。下一批需补教材进度档案、逐次作答时间线、经核实的知识点映射及可撤销的状态更新。

本次身份验收复用上一轮已经跑通的纠错业务，没有再次实调收费模型。真实中文手写整页识别仍存在多空合并、读回冲突及区域偏移；这些质量问题不因账号补全而完成验收。公网部署、身份运营、备份/删除流程、真实平板相机及托管点联合验收继续独立推进。
