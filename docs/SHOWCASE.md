# 人教七上数学：完整一学期展示档案

当前设计预览使用**真实教材身份与项目复核的知识结构**，构造一名七年级学生完整走过一学期的学习档案。它不是随机星空，也不是只有几个节点的 UI 夹具。

## 真实依据与诚实边界

- 教材：人民教育出版社《义务教育教科书·数学七年级上册》，ISBN `9787107382468`。
- 知识结构：R3 候选的六章、75 个技能点和 71 条关系，其中 54 条 `prerequisite_of` 用于当前图谱连线。
- 题目：75 道项目自编参考题与 52 道边界题；题目及知识关系经过独立内容复核，不是教材原文或出版社官方题库。
- 来源审查：`source_verified_ai_reviewed` 只表示官方书目/目录已核对、项目内容经独立 AI 复核，**不等于教师审核、出版社逐节点认证或学生纸书版次确认**。
- 学生、作业、作答和教师核实记录均为**完整演示数据**，不冒充真实学生记录，不用于真实学生评价。没有真实学生授权数据时，页面必须保留这一说明。

数据源：

`services/backend/xueban_backend/data/curriculum/candidates/pep-math-g7-up-9787107382468-candidate-r3-20261021.json`

## 一学期档案内容

时间范围：**2025-09-01—2026-01-29**，与七年级上学期教学进度一致。

| 内容 | 数量或规则 |
|---|---|
| 章节 / 技能点 | 6 章 / 75 个，全部进入图谱 |
| 原图关系 | 71 条；当前绘制 54 条前置关系，其他关系不冒称必过门槛 |
| 作答与订正记录 | 209 条，每个技能点均有可查看证据 |
| 订正父链 | 30 条；`parent_attempt_id` 指向原错误作答，保留时间与题目范围 |
| 阶段性较稳 | 37 个，须跨日期、跨题族独立成功，不能直接指定 |
| 正在巩固 | 21 个，包括订正后仍需新题观察或已有一次独立成功 |
| 需要再看看 | 9 个，保留当前错误，不用后续订正掩盖 |
| 还不判断 | 8 个，有帮助或未核实记录，未知不等于不会 |

档案变化遵循一学期节奏：前两章逐步稳定，中期代数与整式出现错误和订正，后期方程与几何仍有巩固和证据不足。不是为了视觉效果全部点亮，也不是随机分配颜色。

生成与校验：

```sh
cd apps/student-web
node scripts/generate-showcase-semester.mjs
npm test -- --run src/core/showcaseSemester.test.ts
```

生成器只读取已核对候选文件，输出 `src/core/showcaseSemester.json`；同时校验教材节点/关系数量、学期时间、状态规则和订正父链。测试另行核对源文件 SHA-256、75 个节点证据、209 条记录、30 条父链和稳定状态依据。

## 图谱操作

- 全图查看六个章节；左侧章节索引进入单章聚焦，「全部知识点」返回全局。
- 鼠标拖动、触控拖动可移动星图；滚轮、双指手势和右侧加减按钮可缩放，复位按钮回到全图。
- 点击知识点后镜头平滑聚焦并高亮直接关系，同时打开完整学习档案：知识目标、教材位置、常见错误、判读边界、独立作答、错误/订正/题族统计、首次与最近记录、完整历史时间线、原题与订正父链、前置及后续知识。每个节点均可打开；无错误时如实说明，不编造错题。
- 右上角可按知识点或章节名搜索；放大后逐步显示更多标签，减少全局拥挤。
- 动效遵循系统的「减少动态效果」设置；列表视图和键盘方向键、回车操作保留。
- 「展示模式」进入全屏成长讲解：全局 → 章节 → 知识点 → 关系 → 证据共五幕，可自动播放、暂停、前后切换或直接点击进度；空格暂停/继续，左右方向键切换，Esc 退出。证据幕读取同一知识点的详情，手机自动定位到证据内容；退出后恢复页面滚动与原有焦点。整体使用暖纸色教研地图，不使用星空或玻璃视觉。
- 「查看原题与订正」打开结构化原题、学生作答、结果、帮助条件和订正父链说明；不伪造作业照片。

## 建议讲解顺序

1. **先看教材与数据依据**：说明 75 个节点覆盖人教七上六章，学生档案是一学期演示，不是实际学生。
2. **看全局结构**：六章和前置关系构成学习宇宙；位置没有分数含义，暗点也不等于不会。
3. **进入一个章节**：看新知、变式和复习如何留下记录，而不是一次作业决定状态。
4. **看错误与订正**：打开需要再看看的点，比较原错误、订正和后续新题；订正父链可追溯。
5. **看稳定状态依据**：阶段性较稳必须来自不同日期、不同题族的独立成功，看过提示后的订正不算独立掌握。
6. **回到证据**：展示模式最后回到原题和学生作答，说明图谱的价值是证据可追溯，而不是好看或打分。
