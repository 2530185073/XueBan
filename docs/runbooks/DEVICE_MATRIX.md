每个声明支持的“设备＋操作系统＋浏览器版本”组合一行；同一设备的不同浏览器分别登记。只有实际执行并留下截图、录像或日志记录后，结果才能写“通过”；未执行写“待现场”，失败写现象与缺陷编号。网页构建、模拟器、响应式截图或 Android JVM 测试均不能代替本表。

## 学生平板网页逐项验收

| 场景 | 预期 | D1 |
|---|---|---|
| 网页打开与入口 | 生产访问入口可用，资源加载完整，登录和当前学员清楚；无只在开发环境出现的必需入口 | 待现场 |
| 账号登录＋首登改密 | 临时密码登录后必须改密，改密后进入自己的作业；档案 `student_id` 连续 | 待现场 |
| 浏览器 / 系统相机权限拒绝 | 说明当前状态，能重新授权或改用系统选图；不显示已经拍摄或上传 | 待现场 |
| 单页拍摄与预览 | 相机或系统拍摄入口可操作，预览方向正确，可进行网页声明的旋转和裁切 | 待现场 |
| 多页拍摄 / 上传 | 可增删页面、调整顺序、旋转裁切，提交前确认页数；逐页状态和历史翻页正确 | 待现场 |
| 大图、方向信息与格式异常 | 声明支持格式可处理；超出大小/格式限制时有明确提示；不产生不完整但显示成功的作业 | 待现场 |
| 模糊、过暗、反光或缺题 | 按支持范围提醒必要补拍或转待核实；不伪造正确判断 | 待现场 |
| 上传 / 检查中页面刷新 | 已被服务端接收的作业和任务可恢复查看；未知提交沿原标识核对/重试，不重复创建作业或作答 | 待现场 |
| 上传 / 检查中切后台或浏览器终止 | 重新打开后从服务端同步已接收任务；未上传内容按已声明的草稿策略恢复或明确提示补选，不把中断写成完成 | 待现场 |
| 弱网、断网与恢复 | 清楚区分未上传、已接收、处理中和失败；恢复后可继续，不伪造后台进度或重复提交 | 待现场 |
| 本地空间不足 / 缓存写入失败 | 及时提示并提供可执行的恢复方式；已接收的服务器记录仍可查看，未提交内容状态清楚 | 待现场 |
| 登录过期与重新登录 | 重新鉴权后回到该学员合法记录；未确认请求按同一身份核对，不能带入其他学员 | 待现场 |
| 共享设备切换学员 | 退出及切换后不能看到上一个学员照片、历史、图谱、记忆或草稿；返回键和缓存不能绕过隔离 | 待现场 |
| 完整纠错流程 | 拍照 → 识别 → 检查 → 提示 → 新订正 → 再检 → 坐班核实，原题/新图绑定正确、帮助条件保留 | 待现场 |
| 求助、暂停和历史继续 | 真实状态可回看，未接单不显示处理中，仍错/待核实不写成完成，能回到对应题继续 | 待现场 |
| 老师改判 / 识别更正后刷新 | 学生看到最新有效结论；旧结果明确失效，订正及历史引用连续 | 待现场 |
| 图谱与长期 AI | 已核实证据可追溯，未知与候选清楚；偏好/目标可管理，撤销证据后相关结论更新 | 待现场 |
| 举一反三、系统额外预习与自愿小测 | 审核内容可操作；满足学校任务完成、老师有余力确认和孩子自愿；可跳过/退出且无补做负担；学校布置的预习照常可用 | 待现场 |
| 横竖屏、键盘与触屏操作 | 关键按钮、原图和题目可读可操作；输入/软键盘不遮挡必需操作，无阻断性溢出 | 待现场 |
| 网页版本更新 | 刷新/重新打开取得兼容版本；旧页面发生版本冲突时可恢复，账号、历史与已接收任务不丢失 | 待现场 |
| 服务端 / Worker 重启 | 进行中任务恢复或呈现可继续的明确失败；结果不重复，页面能同步实际状态 | 待现场 |

浏览器切入后台后可能暂停页面执行；本轮验收依据是重新打开后的状态恢复、服务端已接收任务的连续性和未上传内容的明确处理。不能把网页验收表中的“恢复”写成已经验证 App 的系统后台续传。
