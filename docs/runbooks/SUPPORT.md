# 支持手册（一线问题 → 处理）

先记下页面上显示的**请求 ID**或任务 ID，再按下表处理。服务器侧排查见 [运维手册](OPERATIONS.md)。

## 学生

| 问题 | 处理 |
|---|---|
| 忘记密码 / 被锁定 | 校区管理员在管理页重置密码，孩子用新临时密码登录后改密。锁定会在 15 分钟后自动解除。 |
| 登录后提示必须改密 | 正常流程：新密码 15 位以上，且不能与旧密码相同。 |
| 一直显示“处理中” | 网络正常时等待 1–2 分钟；仍不动通知值班人检查 Worker。不要重复拍同一页。 |
| 显示“识别/检查失败，可重试” | 点重试一次；仍失败请坐班老师现场人工核实。 |
| 显示“未上传” | 照片还在本机，网络恢复后会继续上传；不要卸载 App。 |
| 觉得判错了 | 在题目里点“申请老师重查”，老师核实后会改判并通知。 |
| 换了平板 | 用同一账号登录即可看到服务器上的历史；未上传的本机照片只在原设备。 |

## 家长

| 问题 | 处理 |
|---|---|
| 报告链接打不开 | 链接可能已过期或被撤销，请老师重新生成。 |
| 报告内容与孩子说的不一致 | 报告只统计老师核实过的作答；如有更正，页面底部会显示更正记录。请联系坐班老师核对。 |
| 想删除孩子的数据 | 联系校区数据治理负责人提交删除申请，处理进度可查询。 |

## 坐班老师

| 问题 | 处理 |
|---|---|
| 队列里看不到某个孩子 | 确认该学员已授权给你的账号；联系校区管理员。 |
| 提交时提示冲突 | 他人刚修改过，页面已刷新，核对后再提交。 |
| 报告发布提示“正在汇总” | 最新改判或活动记录正在汇总，几分钟后再发布。 |
| 额外活动开不了 | 检查三项条件：学校任务完成、已开放分钟数、孩子本人愿意。 |

## 升级到研发

以下情况记录请求 ID、时间和设备编号后提交研发：数据串到其他孩子、已确认的结论丢失或复活、同一作业重复出现、App 更新后记录丢失。上述均为阻断缺陷，试点期间应暂停受影响范围。
