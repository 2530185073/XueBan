# 学伴整体 UI 深度优化计划

日期：2026-10-24。范围：学生网页为主，知识图谱与展示模式包含在内；坐班端做设计令牌对齐，不改变业务行为、数据契约和权限边界。

## 1. 问题诊断

当前界面把几种常见生成式视觉符号叠在一起：深色星空、玻璃面板、发光节点、渐变、英文小号大写标题、装饰性序号、圆角卡片和大量阴影。它们并非单项错误，但组合后产生三个根本问题：

1. **产品调性错位**：像通用 AI 仪表盘或营销页，不像学校作业、托管老师和教研档案。
2. **装饰压过内容**：图谱比原作业更抢眼，英文标签、光效和动画分散对题目、错误和证据的注意。
3. **系统不统一**：登录、上传、历史、图谱、详情和展示模式各自使用不同的视觉语言，缺少稳定的字体、间距、色彩和组件规则。

保留的业务原则不变：学校作业优先；AI 初判与老师核实分开；无记录不等于不会；不打分、不排名；所有结论能回到原题和订正。

## 2. 参考研究与取舍

| 参考 | 采用 | 不采用 |
|---|---|---|
| Brilliant 的学习交互 | 题目先行、清晰行动、用交互解释学习过程 | 游戏化排名、过度奖励和活泼卡通化 |
| Stripe Press 的编辑设计 | 内容优先、宋体标题、纸张和出版物的节奏、明确阅读路径 | 3D 书籍、营销式大动画、过度奢华 |
| Linear 的产品层级 | 克制色彩、明确状态、导航和控件的低噪声、设计令牌 | 深色开发者工具风格、玻璃和荧光 |
| Heptabase 的卡片与白板 | 节点就是完整档案、空间关系和详情联动 | 无限制画布复杂性、面板堆叠 |
| The Pudding 的视觉叙事 | 展示模式按证据顺序讲解，视觉为叙事服务 | 滚动绑架、为炫技定制的无关图形 |
| Impeccable / Taste / Web Guidelines | 设计特异性、动效目的、真实浏览器复核、键盘和触控验收 | 不机械套用“更空、更少、更暗”的规则，不以检测分数替代审美判断 |

结论：不是“再做一套深色主题”，而是改用**作业本、教研批注和真实证据**构成视觉系统。

## 3. 设计概念：作业本里的成长档案

一句话：**把孩子的一页作业，慢慢整理成一本可以理解自己的书。**

四个原则：

- **作业先于图谱**：照片、题目和作答是第一主角，图谱只是组织证据的方式。
- **证据先于装饰**：任何颜色、连线和动效都必须表达真实状态或关系。
- **陪伴先于智能**：文案像老师和教研编辑，不像 AI 产品宣传。
- **清晰先于炫技**：普通学习操作保持安静，只有展示讲解允许一个完整的镜头序列。

视觉母题：作业纸、装订线、页边批注、章节索引、老师的批改符号、可回溯的修订记录。取消“宇宙、指挥舱、玻璃、霓虹、AI 专属英文标签”。

## 4. 设计系统

### 4.1 色彩

- 页面底色：暖纸白 `#F6F4ED`。
- 内容纸面：`#FFFEFA`。
- 主墨色：深松绿 `#18382D`。
- 正文：`#31473D`；辅助：`#6B776E`；分隔：`#D9DED2`。
- 主行动：`#2E6650`；主行动浅底：`#E5EEE6`。
- 需要再看看：赭色 `#A66B3D`；错误与风险：`#A34F42`；过程信息：`#526F88`。
- 展示讲解可使用纯色深松绿背景，但不使用渐变、玻璃或发光。

规则：主行动色只用于行动和当前状态；状态色同时配文字或形状，不单独靠颜色传达。

### 4.2 字体与排版

- 标题：思源宋体 / Noto Serif SC，保留书卷和教研感。
- 正文与控件：思源黑体 / Noto Sans SC，优先本地打包或可靠子集，避免不同平台字体漂移。
- 数字：表格数字使用 tabular-nums；代码、ID 才使用等宽字体。
- 中文正文默认 14–16px，主要操作不小于 14px，正文行高 1.7–1.9。
- 不再使用装饰性全大写英文小标题、装饰性序号和无边界的微型字。

### 4.3 空间、边框与阴影

- 间距序列：4 / 8 / 12 / 16 / 24 / 32 / 48 / 72。
- 圆角只保留 4 / 8 / 12 三档；不为每个容器套卡片。
- 普通内容用间距和底色分层；边框只用于输入、照片、工作区和必要结构。
- 阴影只用于真正的浮层、对话框和菜单，不用于静止卡片与按钮。

### 4.4 动效

- 120ms：按钮和焦点反馈。
- 220ms：状态、折叠和标签变化。
- 420ms：节点聚焦、面板和共享元素转场。
- 展示模式只保留“全局 → 章节 → 节点 → 证据”的一个完整镜头序列，支持暂停和减少动态效果。
- 删除持续呼吸、无意义闪烁、全屏粒子和装饰性视差。

## 5. 页面与组件改造

| 区域 | 改造内容 |
|---|---|
| 应用外壳 | 品牌、文字导航、账号三层清晰对齐；导航使用文本和当前页标记，不再堆图标和浮动容器 |
| 登录 | “打开你的作业本”单一路径；左侧真实作业步骤，右侧简洁表单；删除营销化口号和卡片堆叠 |
| 新作业 | 以拍摄/选择照片为主行动；工作区像平放的作业纸，限制和恢复说明在需要时出现 |
| 纠错结果 | 原图与逐题结果主次明确；状态、提示、求助、订正保持同一组件规则；不让装饰超过题目 |
| 历史 | 改为作业台账和日期时间线；筛选为文字标签，卡片只承载真实作业信息 |
| 知识图谱 | 改为暖纸色“教研地图”：平面墨点、细分章节、真实前置线；去掉星空、光晕、玻璃和英文装饰 |
| 节点详情 | 统一为教研档案页：目标、指标、常见错误、判读边界、完整历史、订正父链、前后知识 |
| 展示模式 | 改名“成长讲解”：以教研幻灯和真实证据为主，不再使用英文 cinema/UI 标签；保留五幕和播放控制 |
| 偏好与目标 | 改为个人笔记本，明确偏好、目标、约定和撤回操作 |
| 练习与预习 | 题目优先，提示放在页边；选做、退出和不欠补做始终可见 |
| 坐班端 | 复用色彩、字体、间距和控件规则；保持工作效率，不强行改成学生纸面风格 |

## 6. 实施阶段

### P0：基线与功能保护

- 固定当前分支、测试、75 节点数据、真实点击/拖动/触控用例。
- 保存登录、工作区、图谱和展示的基线截图。
- 不改变 API、数据格式、权限、上传和任务状态。

### P1：设计令牌与共享组件

- 新增设计令牌和字体加载策略。
- 统一 Button、IconButton、PageHeader、Section、StatusBadge、EmptyState、Tabs、FormField。
- 建立静态内容、悬停、焦点、按下、禁用、加载、错误、成功和空状态规范。

### P2：登录、应用外壳和作业主流程

- 完成登录、导航、上传、原图/结果工作区、历史台账。
- 验证选择文件、相机入口、错误恢复、断网、刷新和真实点击。

### P3：知识图谱和展示模式重构

- 替换视觉令牌、图例、章节、标签、工具栏和节点详情。
- 保留现有布局、缩放、搜索、75 节点档案和订正父链。
- 展示模式改为成长讲解，保留五幕、自动播放、键盘和证据转场。

### P4：学习页面与坐班端对齐

- 优化偏好、目标、练习、预习和选做状态。
- 对齐坐班端字体、色彩、表格、队列和详情，不改变老师工作流。

### P5：多尺寸与规范验收

- 1440、1024、768、390 四档检查；额外检查长知识点名、长题干和空状态。
- 真实鼠标点击、拖动、单指点击、双指缩放、键盘和减少动态效果。
- 75 个节点逐一打开，全部详情和记录可访问。
- 全量测试、生产构建、浏览器无错误、无横向溢出。

## 7. 完成标准

- 首屏 5 秒内能看懂“这是学校作业与成长档案”，而不是通用 AI 仪表盘。
- 核心页面不再使用渐变卡片、玻璃、发光、装饰性英文小标题和无意义数字编号。
- 所有静态页面不依赖动画也成立；动效只解释状态、关系和反馈。
- 真实作业与证据的视觉权重高于图谱装饰。
- 75 个节点、209 条记录和 30 条订正父链均可追溯，数据不因换肤改变。
- 全部现有测试和真实输入验收通过，新发现的问题修复后再复验。

## 8. 计划文件与主要修改面

- `apps/student-web/src/styles.css`：全局令牌、外壳、登录与共享控件。
- `apps/student-web/src/record.css`：作业、历史、原图与订正工作区。
- `apps/student-web/src/learning.css`：图谱、学习页、详情、展示和练习。
- `apps/student-web/src/components/`：页面结构、共享组件和可访问性。
- `apps/staff-web/src/`：仅做统一令牌和必要的视觉对齐。
- `docs/DESIGN_OPTIMIZATION_PLAN.md`：本计划及实施记录。

每个阶段先跑功能测试，再看实际截图；不能只凭 CSS 推断效果，也不能只凭 DOM 点击宣称交互通过。
