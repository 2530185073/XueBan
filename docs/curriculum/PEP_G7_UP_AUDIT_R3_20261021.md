## 审核方另加的反例与计算

这些是本次独立审查补充，未加入候选、不向学生布置，也没有调用付费模型：

| 补充点 | 独立验证 |
| --- | --- |
| 零系数抵消 | `2x+2=2x+2` 恒成立；`2x+2=2x+3` 无解，不可统一按非零一次式处理 |
| 参数导致退化 | `(a-1)x=2` 在 a=1 时无解；其余可除以 a-1。用于检验边界描述，不扩展为必做参数课 |
| 有意义条件不能丢 | `(x-1)/(x-1)` 在 x=1 无意义，即使其他点恒为1；本包未覆盖的分式化简不能借“答案常数”抹掉原定义域 |
| 精确小数 | `0.1×0.3+0.07=0.1`，用有理数复算，不把浮点表示误差当学生误差 |
| 借位与进位 | `1°-1″=0°59′59″`；`13°20′+46°50′=60°10′` |
| 等距反例 | A=(-1,0)、B=(1,0)、P=(0,1)，PA=PB，但 P 不在 AB 上；等距不是中点充分条件 |
| 共线仍缺点序 | A=0、B=3，取 C=8 或 C=-2，均 AB=3、BC=5，但 AC=8 或2；不能只补“共线”就认8 |
| 多视图非唯一 | 两垂直单位圆柱的交集具有两个圆形正投影，却包含 (1,1,0)，不是单位球；两个圆视图不足作唯一性证明 |
| 展开图正反对照 | 六格直线带折转后只有四种面法向，存在重叠；坐标 `(0,0),(±1,0),(0,±1),(0,2)` 的十字扩展网有六种法向。独立离散折叠计算与结论一致 |
| 条件性依赖 | 纯整数角 `20°+35°` 不触发度分秒换算边66；`3(x-1)=6` 先同除后求值不应触发展开节点的负面证据 |

28 组数值等式使用 `Fraction` / `Decimal` 复算，另有6个几何/数值辅助断言通过。这些是数学审查补充，不是模型运行结果；文字阅读与反例推导仍是审核主体。
