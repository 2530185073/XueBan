# 学伴 个人知识图谱与专属智能体

每个孩子拥有一份持续更新的知识图谱、一位能接续历史的 AI 学伴，以及线下及时跟进的教官和学科老师。产品把日常学习、现场辅导、独立验证和家校协作记录为可追溯的成长证据。

本仓库是 2026 年 10 月 16 日建立的研发基础。完整产品围绕个人图谱与专属智能体展开；纠错、知识点分析、举一反三、预习、错题复习与半月小测、家长汇报是智能体调用的学习能力。`blueprint-v3` 是当前产品与开发评审依据。

技术团队接手请先阅读 [开发交接说明](DEVELOPMENT.md)。当前交付包括完整产品蓝图和可运行参考内核，生产功能进度由研发任务清单单独管理。

## 先运行一条真实的程序流程

首次获取并准备环境（macOS / Linux，Python 3.14）：

```bash
git clone https://github.com/2530185073/XueBan.git
cd XueBan
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r prototype/requirements.txt
```

在已激活虚拟环境的项目目录运行：

```bash
python -m pytest prototype -q
python -m prototype.demo
python -m uvicorn prototype.api:app --host 127.0.0.1 --port 8787
```

浏览器进入 `http://127.0.0.1:8787/docs`。请求头 `X-Demo-Actor: teacher-east` 选择固定演示教师；其他演示身份见内核说明。该选择器不提供生产认证，服务只应在本机使用合成数据。

参考内核已实现一部分核心规则，未接真实模型、OCR、对象存储、持久数据库或生产身份系统。完整产品需求、SQL 目标结构和参考 API 子集分别标注，不把文档、示例和生产完成情况混在一起。

## 已固定的产品决策

- 核心是每生隔离的图谱状态与智能体；基础模型可以共享，是否私有部署另外评估。
- 教官负责可观察的学习习惯与执行支持，驻场学科老师负责学科判断和讲解。
- 所有提升必须回到作答或行为证据；练过、接受帮助、独立会做、延后仍会分别记录。
- 半月报告按上海时区的自然月上下半月组织；日常复习间隔另行配置。
- 六项原始需求完整保留；首批内容覆盖可集中在一个年级和学科，以真实题型验收。
- 模型提出建议，业务服务校验权限与状态；个人掌握结论和家长报告有明确责任人。

首批年级、教材、人员配置、真实模型与数据托管方式需要在首次研发评审确定。界面、领域服务、合成数据测试和教学内容整理可以立即按此包拆工开展。
