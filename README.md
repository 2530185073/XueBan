# 学伴：以拍照纠错为核心的完整网页版托管 AI 伴学

**平板拍照纠错是产品核心，所有后续能力建立在拍照纠错记录之上。** 面向托管班，孩子拍下自己的学校作业，系统检查、帮助订正并再次检查，坐班老师按需现场答疑。系统从日常作业、订正与后续表现中完善个人知识图谱，把有依据的薄弱点和变化准确告诉家长，同时控制额外负担。

2026-10-17 最新交付决定：**先交付功能完整的网页版，学生、老师、管理员和家长的全部业务在网页完成；网页实际使用并完善后，再移植 App。** 拍照纠错仍是主入口，个人图谱、长期 AI、每日反馈、半月报告、举一反三、预习小测及管理运行能力均纳入本轮网页交付。现有后端与页面已有多项实现，仍需补齐网页缺口、教研审核和真实验收。开发先读 [完整网页路线](docs/WEB_ROADMAP.md)、[一期范围与发布标准](PHASE1.md) 和 [项目定位](POSITIONING.md)；`blueprint-v3` 保留产品蓝图与历史追溯。

**先把学校作业检查准确、帮助孩子自己改明白，再让纠错证据进入个人图谱和家长报告。** 首个交付关口是照片识别、错误定位、分层提示、孩子订正和重新检查，详见 [纠错核心规格](blueprint-v3/10-纠错核心流程与首发验收.md)。

技术团队接手请先阅读 [开发交接说明](DEVELOPMENT.md)。**网页优先入口：双击 `启动网页版.command`，打开本机 `http://127.0.0.1:8000/learn/`，使用个人账号密码登录。** 每名学员拥有固定学员身份，换设备或改密码不改变学习数据归属；托管班管理员负责开户与重置密码，见 [账号与长期学习档案](docs/ACCOUNT_FOUNDATION.md) 和 [网页运行说明](docs/WEB_LOCAL_RUN.md)。网页共用既有私有照片、纯模型识别与检查、提示、订正再检、PostgreSQL 和历史证据；现有 Android 0.3.0 账号、多页与续跑工程保留为后续 App 移植基础；网页和 App 共用同一账号、业务服务与证据。实际通过的检查和剩余边界见 [验证记录](VALIDATION.md)。这仍是开发联调版，尚未完成正式手写质量与现场验收。

## 参考内核演示（独立于完整网页版）

首次获取并准备环境（macOS / Linux，Python 3.14）：

```bash
git clone https://github.com/2530185073/XueBan.git
cd XueBan
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r prototype/requirements.txt
```

在已激活虚拟环境的项目目录运行：

```bash
python -m pytest prototype -q
python -m prototype.demo
python -m uvicorn prototype.api:app --host 127.0.0.1 --port 8787
```

浏览器进入 `http://127.0.0.1:8787/docs`。请求头 `X-Demo-Actor: teacher-east` 选择固定演示教师；其他演示身份见内核说明。该选择器不提供生产认证，服务只应在本机使用合成数据。

参考内核已实现一部分核心规则，未接真实模型、OCR、对象存储、持久数据库或生产身份系统。完整产品需求、SQL 目标结构和参考 API 子集分别标注，不把文档、示例和生产完成情况混在一起。

## 已固定的产品决策

- 第一期交付完整网页版，包含纠错、图谱、长期 AI、选做、报告及四角色操作；App 列为后续移植。纠错源记录与学习层解耦，使用同一固定学员身份，基础模型是否私有部署另外评估。
- 坐班老师在能力范围内回答作业问题、核实证据；托管支持人员负责习惯和执行，可由同一人兼任。
- 学校新作业可提供独立证据；区分错误事实、可能错因、已核实薄弱范围和未知项，家长能看到依据。
- 半月报告按上海时区的自然月上下半月组织，不以完成小测为前提；未知项不触发强制加题。
- 额外练习默认 0；学校任务完成、孩子愿意且有余力才可少量选做，跳过不扣分、不欠补做。
- 六项学习能力均纳入完整网页范围；C0 先验纠错，R1 允许声明范围受控网页试点，R2 要求完整网页联合验收；首批内容仍须按真实题型测试。
- 模型提出建议，业务服务校验权限与状态；个人掌握结论和家长报告有明确责任人。

已确定首发初中、人教版，研发采用 AI Agent 团队。最初接通 BytePlus DeepSeek 五角色底座后，当前纠错体验已发展为两路整页独立读判、有限消歧和独立视觉核读；实际模型与开关由服务端私有配置决定，见 [当前 provider 路径](services/backend/xueban_backend/providers/README.md)。向量接口的独立联调不等于已建立学生掌握图谱，个人图谱以有效作答证据和明确教材版本为依据。真实作业质量、现场版次、设备与生产部署仍需验收，见 [持续交付记录](docs/CONTINUOUS_DELIVERY.md)。
