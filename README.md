# 学伴 以平板拍照纠错为核心的托管 AI 伴学

**平板拍照纠错是产品核心，所有后续能力建立在拍照纠错记录之上。** 面向托管班，孩子拍下自己的学校作业，系统检查、帮助订正并再次检查，坐班老师按需现场答疑。系统从日常作业、订正与后续表现中完善个人知识图谱，把有依据的薄弱点和变化准确告诉家长，同时控制额外负担。

当前产品规格为 v3.2：明确作业纠错是第一核心，延续托管自主学习与减负边界。纠错、知识分析、举一反三、预习、错题回看和家长汇报围绕学校原任务服务。半月固定汇总已有证据，小测属于可选核实。开发前先阅读 [项目定位与边界](POSITIONING.md)；`blueprint-v3` 目录名保留，内容已同步修订。

**先把学校作业检查准确、帮助孩子自己改明白，再让纠错证据进入个人图谱和家长报告。** 首个交付关口是照片识别、错误定位、分层提示、孩子订正和重新检查，详见 [纠错核心规格](blueprint-v3/10-纠错核心流程与首发验收.md)。

技术团队接手请先阅读 [开发交接说明](DEVELOPMENT.md)。当前交付包括完整产品蓝图和可运行参考内核，生产功能进度由研发任务清单单独管理。

## 先运行一条真实的程序流程

首次获取并准备环境（macOS / Linux，Python 3.14）：

```bash
git clone https://github.com/2530185073/XueBan.git
cd XueBan
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r prototype/requirements.txt
```

在已激活虚拟环境的项目目录运行：

```bash
python -m pytest prototype -q
python -m prototype.demo
python -m uvicorn prototype.api:app --host 127.0.0.1 --port 8787
```

浏览器进入 `http://127.0.0.1:8787/docs`。请求头 `X-Demo-Actor: teacher-east` 选择固定演示教师；其他演示身份见内核说明。该选择器不提供生产认证，服务只应在本机使用合成数据。

参考内核已实现一部分核心规则，未接真实模型、OCR、对象存储、持久数据库或生产身份系统。完整产品需求、SQL 目标结构和参考 API 子集分别标注，不把文档、示例和生产完成情况混在一起。

## 已固定的产品决策

- 核心是每生隔离的图谱状态与智能体；基础模型可以共享，是否私有部署另外评估。
- 坐班老师在能力范围内回答作业问题、核实证据；托管支持人员负责习惯和执行，可由同一人兼任。
- 学校新作业可提供独立证据；区分错误事实、可能错因、已核实薄弱范围和未知项，家长能看到依据。
- 半月报告按上海时区的自然月上下半月组织，不以完成小测为前提；未知项不触发强制加题。
- 额外练习默认 0；学校任务完成、孩子愿意且有余力才可少量选做，跳过不扣分、不欠补做。
- 六项原始需求完整保留；首批内容覆盖可集中在一个年级和学科，以真实题型验收。
- 模型提出建议，业务服务校验权限与状态；个人掌握结论和家长报告有明确责任人。

首批年级、教材、人员配置、真实模型与数据托管方式需要在首次研发评审确定。界面、领域服务、合成数据测试和课程映射和作业支持内容整理可以立即按此包拆工开展。
