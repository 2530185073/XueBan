# 合成图片协议检查

这两张PNG由项目自行绘制，仅含印刷英文题目和算式，不来自教材或学生作业。

- `original.png`：展开 `3(x - 2)`，合成作答为 `3x - 2`。
- `corrected.png`：同题新作答为 `3x - 6`。

它们只验证API图片输入、识别/检查/提示/再检角色和结构化结果传递。不代表手写识别、真实照片、题区坐标、初中全题型或纠错准确率已经通过。真实模型调用必须显式执行 `services/backend/scripts/ark_smoke.py --live`；CI仅使用本地测试，不调用付费接口。

同一模型的不同角色属于一次流水线，不能称作独立模型复核；所有输出仍是候选。后续知识抽取只使用脚本里的自编规则文本，不写学生掌握状态或生产知识图谱。
