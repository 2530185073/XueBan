# 官方 API 响应归一化契约 0.1

输入为供应商真实响应及请求账本，输出为 `schemas/predictions.schema.json`。这是**待适配器遵循的可校验边界**，不是已经实现的腾讯/百度响应解析器，也不包含调用密钥或测试成绩。

一个模型运行文件对应一个已冻结的数据集版本与 split。适配器不能修改 manifest、读取真值来选择候选、根据模型返回结果删题，也不能替人工填写最终确认。用于匹配题框的预标注位置可以与答案标签分开提供；模型请求中不得包含保留集答案或审核结论。

## 状态映射

| 归一化 outcome | 使用条件 | verdict |
|---|---|---|
| `candidate` | 真实判题阶段已完成，响应被严格解析，匹配到正确题目/作答版本，取得明确结论 | `correct/incorrect/partially_correct/unanswered` |
| `unrecognized` | 检出了目标区域，但题干或作答不足以可靠识别；不能把看不清解释成未作答 | `null` |
| `unable_to_judge` | 有可用识别内容，但题目超出范围、条件不足、解法有歧义或核验不足，不能给出判断 | `null` |
| `technical_failure` | 请求超时、限流、HTTP/服务错误、异步任务失败、结构解析失败等；`reason` 记录具体代码 | `null` |
| `missing_detection` | 请求有有效切题响应，但预先登记的目标题没有被切出/匹配到 | `null` |
| `no_output` | 非故障的终态响应中目标题缺少必需结果；不能通过空字符串/默认布尔值变成判对 | `null` |

`missing_prediction` 由评测器在显式 `--allow-missing` 下生成，不是供应商可随意填报的状态。非候选状态必须有非空原因并且 `verdict=null`。处理尚未完成的 pending/running 不应导入最终文件；达到冻结的评测超时后记技术失败，不能无限等到成功再统计。

“提交成功”“任务成功”“切出题目”“答案文本存在”“供应商置信度高”均不等于 `candidate.correct`。只有 OCR 能力的接口没有判题结论；它的输出应进入后续核验流水线，不能把 OCR 成功直接映射为本框架的判对候选。暂未运行核验时可以明确记 `unable_to_judge`，原因 `ocr_only_no_judgment`，但不能把该运行称作完整纠错能力比较。

供应商字段语义须按确切接口核验。例如批改响应里的“未批”和“未作答”是不同状态；识别响应里的答案字段可能只是学生写下的内容，不能视为标准答案。几何证明、等价分式、缺步骤等不确定结论保留无法判断，不能用字符串相等或口算接口能力替代初中数学验证。

## 身份、版本、重复和框匹配

1. 模型没有权力生成最终 `sample_id`。适配器根据冻结的请求映射与题框匹配规则关联 manifest 中的预期题目，结果使用输入时的题目、作答识别版本和指纹。
2. 同题多框、错合题、子题层次歧义应按事先冻结的规则解决；不能在看到正确答案后挑最好的一个返回值。如果暂时不能唯一匹配，保留失败或无法判断，并在隔离的诊断记录中保留原响应引用。
3. 重复回调与重试使用请求账本去重；最终一个 run、一个 sample 只能有一条结果。多个采样候选或重试选择策略必须在请求配置中预先冻结，所有实际调用都保留在 `requests[]`，不能只留下成功调用的时延与成本。
4. 输入内容变化必须生成新运行或新数据集版本。判题候选不能把旧版本结果重命名后套在新订正上。题目拆合导致身份变化，应先更新数据集及映射，不在计分时偷偷改身份。
5. 当前 Schema 不接受“额外未知题”作为已知样本结果。多切/错切引发无法对齐时，必须进入诊断并修订匹配规则后重跑完整版本，不能丢弃问题输出再宣称切题准确。精确题框召回/误检指标留给后续 OCR 专项评测。

## 运行与遥测

保存供应商、接口/模型名、模型版本（未知时附原因）、适配器版本、请求配置 SHA-256。配置记录应包含官方接口 ID、提示词/系统提示版本、模型参数、超时/重试/候选选择策略；所有密钥与签名 URL 必须剔除。`raw_response_ref` 是私有诊断记录的引用，可未知，不把原图、学生姓名或完整响应复制进公开样例。

一次整页请求在 `requests[]` 只出现一次，并列出它覆盖的所有预期 sample，包括漏切的题。每条预测通过 `request_ids` 引用相关请求。同一题经历切题、OCR、判题多次调用时全部记录。真实支付金额未知就填 `null`；重试失败也可能计费，不能擅自归零。

人工复核只写 `human-decisions.schema.json`；模型候选没有 `confirmed` 状态，也没有“人工同意”字段。人工文件不提供时报告中的 `human_final` 为 `null`，明确尚无人工服务效果结果。
