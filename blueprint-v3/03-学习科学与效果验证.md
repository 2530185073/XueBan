# 03｜学习科学与效果验证

版本：v3.1；调研日期：2026-10-16。服务场景是托管班，AI 支持自主完成学校任务，坐班老师仅作现场作业答疑。本文核对原始论文与官方实践指南，将“外部研究发现”“本项目设计推论”“待试点验证假设”分开。研究支持选择教学机制，不构成本产品已经有效的证明。

## 1. 研究告诉我们什么，不能推出什么

| 来源 | 直接支持的认识 | 应守住的证据边界 |
|---|---|---|
| Corbett、Anderson，Knowledge tracing | 可以根据连续作答更新对技能状态的估计，并据此安排练习 | 早期研究来自程序学习；估计状态不是直接看见孩子脑中的知识。出版页标 1994，部分文献按 1995 引用，以 DOI 识别。[原论文](https://link.springer.com/article/10.1007/BF01099821) |
| Piech 等，2015，Deep Knowledge Tracing | 序列模型可以预测未来答题表现 | 预测指标改善不等于真实学习增益，更不能替代独立测评。[NeurIPS 论文](https://papers.neurips.cc/paper_files/paper/2015/file/bac9162b47c56fc8a4d2a519803d51b3-Paper.pdf) |
| Khajah 等，2016，How deep is knowledge tracing? | 在其评估中，扩展 BKT 可达到与 DKT 相近的表现 | 不能据此断言简单模型永远最好；它支持保留解释性基线并公平比较。[作者论文](https://arxiv.org/abs/1604.02416) |
| Liu 等，2022，pyKT | 统一预处理和评估很重要，错误设置会产生标签泄漏与指标虚高 | 开源榜单不能证明本地教材、年级与真实任务策略有效。[NeurIPS 论文](https://papers.neurips.cc/paper_files/paper/2022/hash/75ca2b23d9794f02a92449af65a57556-Abstract-Datasets_and_Benchmarks.html) |
| IES/WWC，2007，学习与教学组织指南 | 建议分散学习、交替例题与练习、检索测验和解释性提问，并区分证据等级 | 不提供一个适用于所有孩子的固定遗忘曲线或题量。[官方指南](https://ies.ed.gov/ncee/wwc/practiceguide/1) |
| Roediger、Karpicke，2006 | 阅读材料实验中，检索练习的延迟保持优于同次数重读，短期结果与延迟结果可能不同 | 材料和任务有边界，不能直接换算为本项目数学提分幅度。[原论文摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/) |
| EEF，2025 第二版，元认知与自我调节指南 | 在具体学科中教计划、监控和评价，并示范思考和逐步撤除支持 | 完成计时任务不等于形成自我调节能力，不宜只靠积分维持行为。[官方指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition) |
| EEF，2021，反馈指南 | 反馈应推动下一步学习，必须安排学生理解并使用反馈的机会 | 反馈很多、很及时或写得很长都不自动表示有效。[官方指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback) |
| Bastani 等，2025，高中数学 RCT | 无护栏 AI 可提高有辅助练习表现，同时损害撤去 AI 后的表现；教学护栏可缓解负效应 | 土耳其一所高中约千人、四次课程；有护栏组未显示相对对照组的独立考试显著优势，不能宣传为“护栏保证提分”。[PNAS 正式论文](https://doi.org/10.1073/pnas.2422633122) |
| Kestin 等，2025，大学物理 RCT | 特别设计的 AI 辅导在所测课程中取得较好的课后表现 | 194 名符合纳入条件的哈佛大学学生、两节课；并非 K12 长期专属智能体的验证。[论文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/) |

这组证据对项目最直接的提醒是：**学生在有 AI 时完成得更好，与学生离开 AI 后真正会做，是两个结果。** 产品应区分两种条件；独立表现优先从后续学校新作业中观察，不能据此要求每个孩子额外接受测验。

大学物理试验采用了教师编写的内容、详细解答和结构化交互；其结果不能归因于仅仅接入某个模型。高中数学试验也明确把教师提供的答案、常见错误和提示纳入护栏。两者共同提示本项目需要可靠内容、适量提示和真实帮助条件记录；不能把“长期记忆＋聊天窗口”本身当作教学机制，也不能把研究中的课堂实验流程直接搬成托管班额外课程。

## 2. 把研究转成低负担的日常支持

以下是本项目的设计推论，需在实际托管情境中验证。研究支持某种机制，不等于机构有理由增加孩子的学习任务。

### 2.1 帮孩子完成原有任务，并逐步减少代解

默认流程是“孩子先尝试学校题目—AI 给适量提示—孩子继续完成—必要时坐班老师现场答疑—系统记录帮助条件”。不强迫孩子反复猜答案；短提示无效时可以说明关键一步或请老师，避免长时间消耗造成压力。坐班老师处理当前作业疑难，不另排补课、小组补差或机构教学进度。

反馈指向可执行动作，例如检查括号内第二项是否也乘了外部因数，并记录孩子如何修改。刚看过解释的正确作答属于有帮助订正；以后学校出现未见过的新题，且经核实没有提示或答案帮助，才形成独立表现证据。这承接 EEF 强调的“规划学生如何使用反馈”，不要求每次反馈后都另加一道题。[EEF 官方说明](https://educationendowmentfoundation.org.uk/news/eef-publishes-new-guidance-report-teacher-feedback-to-improve-pupil-learning)

### 2.2 间隔与检索优先融入已有学校任务

学校后续作业自然再次涉及相同知识时，可以观察孩子是否记得和会用；只要新题、帮助条件与间隔清楚，就能补充图谱。未再遇到该范围时保留未知，不强迫加测。复述当前题思路或提交前回看，也应控制时间，不变成机械打卡。

额外错题复习、举一反三、机构建议的下一课预习、轻量小测仅在学校任务完成、有余力、孩子愿意时，按实际必要性选择；孩子随时可停，不产生补做债务。学校明确布置的预习属于原任务，不因其名称为“预习”而当作机构加项。

### 2.3 自主性是适量支持逐步减少

现场人员帮助孩子确定学校任务、说明卡点、使用检查策略，再根据实际情况减少提醒。教官与坐班老师可由同一人员兼任，职责记录区分即可；这不是五个独立岗位的用工要求。

观察“5 次可观察机会中，3 次无需提醒启动任务”，同时记录作业量、难度、到班时间和主动求助。提醒减少可能来自能力改善，也可能来自孩子放弃或现场没人观察，必须结合完成质量和感受判断。合理求助不扣自主性分，不推断心理或人格标签。

### 2.4 图谱服务家长理解，不制造额外任务

学校日常作答和答疑提供证据，知识点分析区分已观察错误、可能原因、已核实薄弱范围与未知。半月报告固定生成，可选小测只是附加证据来源，不是报告资格。

每条给家长的薄弱判断须显示原作业日期和步骤、帮助条件、频次分母、可信程度、坐班答疑及最小下一步。举一反三、预习、小测等保留工具入口；未使用不意味着服务缺失，图谱节点没有变绿也不意味着孩子没有努力。

## 3. 先验证托管服务是否更自主、更轻松

### 3.1 日常可行性试点

先观察两个自然半月周期，以正常学校任务为载体，不默认增加入班测验或期末测验。检查采集是否打断写作业、AI 是否帮助继续自主完成、求助是否及时处理、现场人员是否增加负担、报告能否让家长理解具体问题。

可使用试点前的日常服务记录作为基线，并同步记录学校作业量、难度、缺勤、校外支持和实际使用条件。保留未使用、跳过额外活动和退出的孩子；不能只分析积极使用者来说明效果。未确认的独立性不强行填成独立。

### 3.2 研究性效果验证另行组织

若希望回答更严格的学习效果问题，可以另行设计对照研究，包括适当时长、样本量和延迟测验，但它不是托管班日常产品的强制流程。研究参与、额外测验、时间负担和数据用途须向家长与孩子单独说明并取得明确同意；拒绝不影响正常服务或半月报告。

研究优先复用适合且授权的学校任务资料。额外测验仅在研究问题确实需要时设置，并预先限制负担、允许退出；不能借“完善图谱”自动给所有学生推送。可选小测参加者具有自选差异，不可与未参加者直接比较并宣称因果效果。

若设置对照组，应尽量匹配学校任务、总时间和成人关注量，预先指定主要指标、分析和缺测处理。随机分配与按班级分配的统计单位须一致，样本量要考虑聚类和退出；分析保留原分组，不因学生少用 AI 就删除。若只能做前后观察，则明确无法排除学校教学、作业变化等影响。

研究中的独立、延迟和迁移测试可回答特定学习问题，但不能取代日常产品的四项主指标，更不能将大学两节课研究转译为本地儿童长期提分承诺。

## 4. 四项主指标与辅助指标

| 主指标 | 建议口径 | 解释边界 |
|---|---|---|
| 学校作业完成质量 | 已完成且经适当核验的学校任务 / 本次实际布置且可判断的学校任务；分首次作答、提示后订正、未判断 | 同时列分母、作业量和难度；上传率不等于完成质量，不能逼孩子赶完 |
| 自主性与提醒依赖 | 经核实独立完成的新作业、主动有效求助、人工与 AI 提示次数或强度，均附可观察机会数 | 不把所有求助当依赖，也不把帮助条件未知算独立 |
| 孩子负担与感受 | 学校任务耗时、平台额外耗时、被追加活动数、疲劳/压力的简短自述、暂停和退出情况 | 不做心理诊断；自述可不填；题量、难度和到班时间变化需要注明 |
| 证据可靠性 | 抽样检查识别与判断、知识点映射、帮助条件、错误事实与原因假设分离、频次分母、原图追溯 | 老师采纳率不是准确率；要核对原始材料并保留未知与反证 |

辅助观察包括现场答疑响应、每生人员耗时、报告按期生成、家长能否准确说出孩子的具体卡点与下一步、申诉改判闭环和单位服务成本。家长打开率、满意度、续费率反映服务体验，不能替代上述四项。

每半月均生成报告：有证据就说明，有不足就列明范围和原因。未参加小测不记零分、不扣分、不产生补测义务。不同孩子学校任务不同，不横向比较原始正确率或排名；同一孩子跨期比较也需说明分母和任务组成的变化。

日常报告不为统计显著性制造题量；若另行同意研究，则报告样本、缺测、不确定区间及选择偏差。学校考试可以作辅助资料，但试卷难度、课程范围和外部支持不同，不单凭一次升分归因于系统。

## 5. 知识追踪模型单独验证

模型预测任务与产品效果分开验收。历史资料中的帮助条件、题目新旧、现场核验要可追溯；帮助未知或有提示作答不能混进独立结果标签。学校作业与可选练习的来源要分层，不能仅凭来源排除学校新作业的价值。

对已有学生预测后续表现，严格按时间切分；对新入班学生测试冷启动，保留未进入训练的学生。归并重复上传与同一次答案的多知识点记录，避免标签泄漏；再看不同题族、章节和校区的表现。规则基线、BKT 和复杂模型在相同可用信息下比较。

除 AUC 外，检查概率校准、Brier 分数或对数损失、分群误差及证据不足时能否不下结论。数据少时报告不确定性，不以微小指标差异换掉可解释规则。图谱是否漂亮、预测是否更准，都不能单独证明孩子更自主或压力更小。

新模型先在影子模式运行，检查它是否错误增加任务、把一处错误扩大为整体薄弱、把原因假设说成定论。上线后的改进目标是更准确解释原有证据并减少无效帮助，不是追求更多学习时长。

## 6. 发布与沟通的证据门槛

上线前设定错误分级和回退条件，用固定材料检验；要能申诉、改判、重算状态、使旧记忆和未发报告失效。隐私、越权与严重误导问题单独处理。学校作业模式中保留合理求助入口，不能为了采集“无帮助数据”禁用孩子需要的帮助。

阶段结论依次是日常支持能够可靠运行、观察到作业质量/自主性/负担的变化、经单独设计的对照研究获得有边界的效果证据。对应表述不能越级。

现阶段可以说：“我们依据孩子每天的学校作业和现场答疑，持续整理具体卡点，每半月向您说明依据与最小下一步，帮助孩子逐步自主完成任务。”不能承诺必然提分，也不把研究性测验成为默认学生负担。
