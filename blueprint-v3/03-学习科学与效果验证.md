# 03｜学习科学与效果验证

调研日期：2026-10-16。本文核对原始论文与官方实践指南，将“外部研究发现”“本项目设计推论”“待试点验证假设”分开。研究支持选择教学机制，不构成本产品已经有效的证明。

## 1. 研究告诉我们什么，不能推出什么

| 来源 | 直接支持的认识 | 应守住的证据边界 |
|---|---|---|
| Corbett、Anderson，Knowledge tracing | 可以根据连续作答更新对技能状态的估计，并据此安排练习 | 早期研究来自程序学习；估计状态不是直接看见孩子脑中的知识。出版页标 1994，部分文献按 1995 引用，以 DOI 识别。[原论文](https://link.springer.com/article/10.1007/BF01099821) |
| Piech 等，2015，Deep Knowledge Tracing | 序列模型可以预测未来答题表现 | 预测指标改善不等于真实学习增益，更不能替代独立测评。[NeurIPS 论文](https://papers.neurips.cc/paper_files/paper/2015/file/bac9162b47c56fc8a4d2a519803d51b3-Paper.pdf) |
| Khajah 等，2016，How deep is knowledge tracing? | 在其评估中，扩展 BKT 可达到与 DKT 相近的表现 | 不能据此断言简单模型永远最好；它支持保留解释性基线并公平比较。[作者论文](https://arxiv.org/abs/1604.02416) |
| Liu 等，2022，pyKT | 统一预处理和评估很重要，错误设置会产生标签泄漏与指标虚高 | 开源榜单不能证明本地教材、年级与真实任务策略有效。[NeurIPS 论文](https://papers.neurips.cc/paper_files/paper/2022/hash/75ca2b23d9794f02a92449af65a57556-Abstract-Datasets_and_Benchmarks.html) |
| IES/WWC，2007，学习与教学组织指南 | 建议分散学习、交替例题与练习、检索测验和解释性提问，并区分证据等级 | 不提供一个适用于所有孩子的固定遗忘曲线或题量。[官方指南](https://ies.ed.gov/ncee/wwc/practiceguide/1) |
| Roediger、Karpicke，2006 | 阅读材料实验中，检索练习的延迟保持优于同次数重读，短期结果与延迟结果可能不同 | 材料和任务有边界，不能直接换算为本项目数学提分幅度。[原论文摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/) |
| EEF，2025 第二版，元认知与自我调节指南 | 在具体学科中教计划、监控和评价，并示范思考和逐步撤除支持 | 完成计时任务不等于形成自我调节能力，不宜只靠积分维持行为。[官方指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition) |
| EEF，2021，反馈指南 | 反馈应推动下一步学习，必须安排学生理解并使用反馈的机会 | 反馈很多、很及时或写得很长都不自动表示有效。[官方指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback) |
| Bastani 等，2025，高中数学 RCT | 无护栏 AI 可提高有辅助练习表现，同时损害撤去 AI 后的表现；教学护栏可缓解负效应 | 土耳其一所高中约千人、四次课程；有护栏组未显示相对对照组的独立考试显著优势，不能宣传为“护栏保证提分”。[PNAS 正式论文](https://doi.org/10.1073/pnas.2422633122) |
| Kestin 等，2025，大学物理 RCT | 特别设计的 AI 辅导在所测课程中取得较好的课后表现 | 194 名符合纳入条件的哈佛大学学生、两节课；并非 K12 长期专属智能体的验证。[论文全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/) |

这组证据对项目最直接的提醒是：**学生在有 AI 时完成得更好，与学生离开 AI 后真正会做，是两个结果。** 产品必须同时记录，且以后者作为效果判断的重要依据。

大学物理试验采用了教师编写的内容、详细解答和结构化交互；其结果不能归因于仅仅接入某个模型。高中数学试验也明确把教师提供的答案、常见错误和提示纳入护栏。两者共同提示本项目应投资教研内容、反馈设计和独立验证；不能把“长期记忆＋聊天窗口”本身当作教学机制。

## 2. 可采用的机制与产品实现

以下是结合证据提出的设计推论，需在本地学生群体中验证。

### 2.1 让纠错产生后续行动

纠错流程采用“学生先尝试—定位具体步骤—给适量提示—学生修改—独立验证”。若概念尚未建立，可以直接给清楚的示范，再让孩子完成一题；不把不断反问包装成对所有孩子都有效的苏格拉底教学。

反馈应指向可执行动作，例如“检查括号内第二项是否也乘了 3”，并在页面内安排修改或解释。系统记录学生实际怎样响应反馈，而非只记录解析已展示。这对应 EEF 强调的“规划学生如何使用反馈”。[EEF 官方说明](https://educationendowmentfoundation.org.uk/news/eef-publishes-new-guidance-report-teacher-feedback-to-improve-pupil-learning)

### 2.2 把检索与间隔放进错题流程

错题复习先提供不含答案的题目，让学生从记忆中尝试，再给反馈。刚看完解析的重做作为订正，隔一段时间的新题作为保持检查。以计划中可调整的复习日期代替一条声称适用于所有人的遗忘曲线。

复习应有新题和适量旧题：旧题帮助回看典型错误，新题减少仅记答案造成的假象；变化情境检验迁移。不能把不停做难题、增加挫败感等同于“有效困难”，难度调整要看实际理解与帮助条件。

### 2.3 习惯培养服务于越来越独立

线下教官围绕具体任务示范：开始前说目标，卡住时说明卡在哪，结束后解释用了什么方法、下次如何检查。前期可以提醒与陪做，随后逐步减少提示，观察孩子能否在没有提醒时继续使用策略。

观察单位是行为与情境，如“本周 5 次作业中 3 次提交前主动检查符号”，而不是抽象的“自律等级”。记录需要包含机会数和提醒情况；出勤减少、教师没观察到、设备离线都不能算行为下降。教师仍需判断何时是学科困难、时间不足或环境问题。

### 2.4 六模块共同服务个人图谱

纠错提供问题证据；知识点分析形成可验证假设；举一反三提供新题与迁移证据；预习检查下一课的必要基础；错题与半月测补充延迟、独立证据；家长汇报说明已采取的支持及下一步。个人智能体据此持续安排任务，不通过对话长度、在线时间或积分多少推断掌握。

六模块首期都应存在。先限定服务人群、课程范围和内容库，可以降低风险；删掉延迟验证或半月测会让产品无法检验自己的核心承诺。

## 3. 试点分两步：先跑通，再检验增益

### 3.1 可行性阶段

建议至少运行两个完整半月周期，并留出一次延迟复测。可从一个校区的小班开始，目标是发现内容、流程与工作量问题，而不是用几十个学生给出确定提分结论。

观察六模块是否完成循环、图谱状态能否追溯、智能体是否引用正确孩子的当前证据、老师能否按计划处理、孩子是否愿意继续、家长是否理解报告。同步记录学校教学进度、校外辅导、缺勤及实际使用量。保留失败和退出记录，不能只挑出坚持到最后的优秀案例。

### 3.2 效果验证阶段

建议设计覆盖 8–12 周及后续保持测验的评估，具体时长与样本量由课程和统计功效分析确定。处理组采用图谱驱动的完整服务；对照组采用现有标准服务，并尽量匹配学习内容、总时间和老师关注量。这样估计的是整套服务相对现有流程的增益，不能声称单独识别了“AI”或“图谱”的贡献。

在可行且适当的情况下随机分组。若学生之间共享老师和练习、容易互相影响，可以按班级或时段分配，但分析时也要处理聚类；只有很少班级时，随机分配本身仍不足以支持精确结论。样本量应考虑预期差异、班内相关、缺测和退出，不能先定一个好招募的人数再声称充分。

预先写明主要指标、测验时间、纳入规则、缺测处理和分析方法。评分者尽量不知道分组，使用统一评分细则。主要分析按原分组保留学生，补充报告实际参与程度；不能把不使用系统的学生全部删除后只报高参与者收益。

若现实只能前后测，应写成“试点期间观察到的变化”，并说明无法排除学校教学、额外补课、熟悉题目等影响。不要将其写成系统造成的增益。

## 4. 学习效果、系统质量与运营指标分别看

| 类别 | 指标与口径 | 容易误读的地方 |
|---|---|---|
| 主要学习结果 | 预先指定课程目标的延迟、无 AI 辅助测验表现；统一计分，报告基线和组间差异 | “做题当场全对”不能替代延迟独立表现 |
| 迁移结果 | 未直接练过的同目标新题及变化情境题表现，分层报告 | 只换数字不能代表广泛迁移 |
| 独立性 | 有提示与无提示作答分别统计；观察提示逐步撤除后的表现 | 提示少也可能是孩子放弃求助，需结合完成情况 |
| 图谱可信度 | 抽样核验状态与原始证据是否一致、证据不足是否被正确标记 | 图谱变绿数量不等于进步大小 |
| 教学质量 | 错判、错误讲解、错误题目、漏识别、越过题型边界分别统计 | AI 结果被老师接受不自动等于正确，应独立复查样本 |
| 服务可行性 | 每生每周老师和教官投入时间、积压、完成周期、缺席与退出 | 需要计算备题、审核和报告时间，不能只计点击耗时 |
| 家长理解 | 能否说出孩子重点、证据和下一步；反馈是否被处理 | 打开率、满意度、续费率不能替代学习效果 |
| 单位成本 | 每个实际完成的服务周期的模型、内容、审核、人力和设备摊销 | 学生多了以后审核量不一定线性下降 |

半月小测首先用于调整个人计划。为效果比较，应额外保留独立于推荐题库的测验蓝图和测试题；若训练和效果测验反复使用同一题，结果会混入记忆答案的影响。个人不同试卷不能直接比较原始分，应采用共同锚定内容或经验证的等值方法。

呈现人数、有效测验人数、缺测率、平均变化和不确定区间；按年级、起点和参与度查看差异，但小样本分组结果只作探索。学校考试可作辅助结果，需说明试卷难度与教学范围的变化。

## 5. 知识追踪模型单独验证

模型评估至少区分两种问题：对已服务学生预测未来表现，以及对新入班学生进行冷启动。前者严格按时间切分，后者保留从未进入训练的学生；再增加新题族、不同章节和必要时跨校区检验。

数据处理先归并同题重复上传和多知识点展开记录，避免相同答案跨训练与测试泄漏。比较透明规则、简单统计/BKT 与复杂序列模型，使用同一标签、时间窗和可用信息。除区分对错的 AUC 外，还看概率校准、Brier 分数或对数损失、不同群体误差及证据不足时能否拒绝下结论。样本小时报告不确定性，不以微小数字差异定胜负。

离线预测更好之后，先在影子模式观察推荐变化，再做受控上线。新模型可能为了预测容易的题而偏向简单题，因此必须检查任务覆盖和独立学习结果。没有真实策略评估，不能说“准确率更高所以孩子学得更好”。

## 6. 发布与宣传的证据门槛

上线前先由团队约定可接受错误范围、严重错误定义与回退条件，再在固定评测集上验证；不要看到结果后修改门槛。至少要求错误可申诉、老师能纠正、状态能重算、过期计划和报告会失效，且独立测验期间无法读取答案或调用提示工具。

阶段结论分三级：第一，六模块与个人图谱能够可靠运行；第二，观察到独立表现和服务质量的变化；第三，在预定对照评估中得到有边界的增益证据。每一级只能支持相应表述。

当前可对家长说：“我们会持续记录孩子的学习证据，安排有针对性的练习与复测，由老师确认重点并调整计划。”在获得本地验证前，不使用“必然提分”“哈佛证明适合所有孩子”“图谱准确测出潜力”等说法。长期智能体是否带来更好的保持、迁移与自主学习，是这个项目需要持续回答的问题。
