# 04｜完整产品需求与页面流程

版本：v3.3，一期 App 与后续完整产品分期。服务场景是托管班：平板 AI 帮助孩子自主完成学校课程与作业，减少代解、无效提醒和压力；坐班老师仅处理现场作业答疑。产品主线为“学校作业检查 → 错误定位 → 孩子订正 → 再检查 → 个人知识图谱 → 家长反馈”。本文件定义生产目标，参考内核仅覆盖部分规则。

一期实施范围以 [PHASE1](../PHASE1.md) 为准：学生拍照纠错 App、必要坐班工作台与生产基础服务。下文图谱、长期智能体、预习、选做、小测及家长/校区完整分析页面是后续蓝图，一期不展示空入口；无需实现这些页面才能保存作答或登录使用。

## 1. 服务边界与角色入口

| 使用者或职责 | 首页首先回答 | 入口 |
|---|---|---|
| 学生 | 怎样检查自己的作业、哪里需要订正、是否已改对 | 一期：拍照纠错、继续订正、历史作业、求助；后续：图谱与个性化学习模块 |
| 坐班答疑职责 | 哪个孩子的当前学校作业需要解释或核验 | 现场求助、原作答核验、问题证据、处理记录 |
| 现场习惯支持职责 | 谁需要启动、检查、休息或环境方面的帮助 | 到班任务、观察、提醒与约定、交接 |
| 校区管理职责 | 服务是否及时、问题依据是否可靠、家长是否得到说明 | 求助与复核、共性问题、半月报告、家长沟通、质量 |
| 家长 | 孩子的具体问题是什么、依据是什么、已经怎样帮助 | 半月报告、代表作业证据、现场答疑、最小下一步 |

这是权限与职责划分，不是五名员工的配置要求。教官和坐班老师可由同一位有相应能力的人员兼任；切换操作时标明职责，学科判断和行为观察分别记录。校区负责人也可承担报告审核与沟通。后台内容、规则和系统维护不等于另设日常授课岗位。

不在学生流程设置机构课程表、补课排课、强制补差班或“完成图谱所需题量”。AI 支持原学校任务，坐班人员答疑，不用产品安排替代学校教学。

## 2. 入班与专属智能体

一期确认学生与监护授权、日常作业来源和首发内容范围即可开始拍照纠错，不强制创建长期智能体。后续再补充教材/学校进度、必要支持条件并启用专属智能体。学校进度来源需标注，未知时不猜下一课。联系方式与模型使用的学习上下文分开保存。

入班不默认另发测验。先从真实作业建立局部图谱，允许大量“未知”；家长说“总是粗心”仅作为待核实描述。现场围绕当前题追问可以帮助理解卡点，但不发展成独立测评课程。

专属智能体记住当前学校任务、已确认事实、近期困难和曾有效的帮助方式。它的长期价值在连续理解与减少重复解释，不以让孩子聊天更久或依赖学伴为目标。

## 3. 学生端页面规格

### S01 平板拍照纠错首页

平板默认主屏就是拍照纠错，首屏突出“拍作业检查”“继续订正”和“请坐班老师帮忙”，已核实但尚未完成的订正可直接继续；一期不开放图谱入口，后续在次级入口启用。页面编号沿用已有文档，不表示功能优先级。纠错详细交互与 C0 验收见 [10 纠错核心规格](10-纠错核心流程与首发验收.md)。

学校任务清单与进度作为拍照作业的上下文辅助呈现：科目、来源、布置日期、要求、真实截止时间、完成状态和求助。任务类型明确区分 `task_origin=school` 与 `task_origin=optional`。学校布置的预习、订正属于原任务。

AI 可以帮助梳理顺序、解释题意、拆成可完成步骤。没有完成的学校任务、需要休息或孩子没有余力时，不推额外题。首页最多突出当前动作和求助，不用“红色欠账”“图谱达标率”催促。

学校任务完成后，可显示“已完成学校任务，可以休息或结束”。若确有必要，额外举一反三、复习、预习、小测仅在学校任务已完成、有余力、孩子愿意三项同时满足后出现；允许拒绝、跳过和随时结束，不产生到期、补做或扣分。

资料缺失时显示“学校任务信息待确认”；分析等待不阻止继续其他学校任务；离线保留已经输入的学校作业；计划因改判过期时不静默替换已开始任务。

### S02 我的知识图谱

默认展示当前学校课程相关节点，可切换章节列表。颜色配文字，节点状态须说明范围、证据数、帮助条件和未知部分。

节点侧栏分四块：

1. **观察到的错误 `observed_error`**：原作业日期、页码题号、具体错误步骤。
2. **可能原因 `suspected_cause`**：例如可能不清楚负号作用范围，明确标待核实。
3. **已核实薄弱范围 `verified_weak_scope`**：经确认的具体子范围、相关题目分母、现场答疑依据和反证。
4. **未知 `unknown`**：没有遇到、帮助条件不明、材料不清或证据互相矛盾。

一道题答错不自动说明整章薄弱；前置边只帮助查找原因，不沿链全部标红。图谱不足不触发强制训练。不同阶段快照可比较，但必须保留范围和分母，不能把变绿数量当成能力总分。

### S03 我的 AI 学伴

学伴围绕当前学校任务提供读题帮助、适量提示、已审核的相关解释、检查方法和现场求助。优先让孩子继续思考，避免直接代做；孩子连续卡住时可以给更明确的一步或转坐班老师，不以无限反问制造压力。

涉及历史表现时引用可追溯证据；不确定时说明尚不清楚。AI 初筛与已核验结论分开标注，未经核验的原因推测不写入长期薄弱结论，也不直接发给家长。帮助记录必须写清提示、关键步骤或完整答案暴露。

孩子可查看可展示的个人记忆并提出更正；“今天不想写”不能变成长期人格标签。故障时显示现场求助入口。日常学校任务始终允许合理求助，不能为了采集无帮助数据强制关闭帮助。

### S04 作业采集、纠错与帮助条件

支持整页或单题，检查模糊、遮挡、题目与作答完整性；保存原图、页码题号、学校布置日期和识别版本。上传动作尽量嵌入已有完成流程，不要求每一步反复拍照。

初筛链为 `received → processing → provisional → confirmed`；不清晰或有争议进入 `needs_material / awaiting_review`。学生可以使用明确标注的 AI 提示继续原任务，最终写入图谱的错误事实须经过可追溯核验。疑难或不一致交坐班老师，不让每个普通作答都形成额外现场讲课。

订正作为新作答，通过正式契约待补齐的 `parent_attempt_id` 关联被订正的作答，保留实际帮助、完成时间和核验状态。修改后必须重新检查，显示原题订正通过、仍需帮助或待核实；不能仅点“已完成”就通过。学校原题的纠错与订正不受额外练习门禁限制。提示后做对属于有帮助订正，不冒充独立掌握。学校后来布置的未见过的新题，经核实无 AI/成人/同伴提示且非刚订正原题，可以直接形成独立证据，无需转成机构测验。

核实要结合现场观察、工具使用记录与作答过程，不能仅凭学生勾选“独立”下结论；无法核实即未知。申诉和改判追加记录，重算图谱并使错误记忆、待发报告失效。

### S05 知识点分析与可选举一反三

题目详情先展示错误事实，再展示可能原因和需要核实的范围。优先利用当前作答过程、已有学校同类题和坐班答疑，不默认推送诊断题。

可选举一反三入口要再次检查三项自愿门槛，并说明用途。选择少量有必要的同技能、结构变化或迁移题，不按每道错题固定追加三题。学生拒绝或中途结束只记录未参与，不判不努力或不掌握。

题目须审核；没有适合内容时取消推荐。到时间预算、孩子疲劳、连续卡住或不愿继续时停止；不自动产生下一轮练习。已有证据不够时，等待下一次学校作业即可。

### S06 下一课预习

独立板块分“学校布置”与“可选建议”。前者进入学校任务清单；后者仅在任务完成、有余力、孩子愿意时按必要性展示。

读取有来源的下一课信息，结合个人图谱帮助理解必要基础、浏览学校指定内容或记录带入课堂的问题。不安排机构提前授课，不以预习结果认定未学知识退步。学校课序改变时旧建议失效，课程未知则不自动猜课。

### S07 错题整理与可选轻量小测

错题随学校作业自动整理，按知识点、错误步骤、日期、帮助条件筛选。支持回看原作答、订正和坐班答疑；重复上传去重，误判撤销后移出有效统计。整理本身不要求孩子重新抄题或完成额外练习。

半月小测是轻量可选工具，不是服务必经关卡。只有三项自愿门槛满足且现场认为必要时提供；学生未参加、不愿继续或缺席，不扣分、不欠补测、不影响半月报告。可选题量与时间提前说明，不以“积累证据”为由临时加量。

如选择参加，记录题目范围、帮助条件和实际时间；愿意接受帮助时转为有帮助活动，不能继续算独立小测。网络中断不自动记错。不同题目的原始分不直接横向排名。

### S08 成长档案

时间线区分学校任务完成、获得帮助、后续独立表现、习惯观察和未知部分。正常学校新题在明确独立条件下完成，与额外练习一样可以提供成长证据。

进步卡包含原问题、实际答疑/提示、后来在哪份作业中怎样表现、帮助条件、可信程度与限制。保留反复，不只筛好消息。习惯卡使用“5 次可观察机会中，3 次不用提醒检查”，不用抽象专注力、自律或人格分数。

## 4. 坐班答疑与现场习惯支持工作台

| 页面 | 现场操作 | 保存结果 |
|---|---|---|
| T01 当前作业求助 | 查看孩子卡住的学校题目与已尝试步骤，答疑或转适合人员 | 当前题的答疑内容、时间、帮助层级与是否仍有疑问 |
| T02 证据核验 | 核对疑难原图、错误步骤、帮助条件及知识点归属 | 核验/无法判断/改判记录；不能填写没有依据的掌握率 |
| T03 具体问题卡 | 区分事实、假设、核实范围、未知；查看同类学校题的分母 | 有边界的问题说明和最小下一步 |
| C01 任务与环境支持 | 协助启动、说明卡点、安排休息、检查提醒 | 可观察事实、提示强度、机会数和孩子反馈 |
| C02 约定跟进 | 逐步减少提醒，回看约定是否适合 | 是否实施、当次条件、仍需支持，不给人格诊断 |
| M01 报告事实确认 | 由有相应职责的人员核实学科与习惯段 | 当前版本、证据引用、无法确认项和确认人 |

工作台没有补课排课、机构教学计划或强制复测队列。坐班老师围绕学校作业答疑；报告整理可由系统和校区管理职责完成，必要学科疑问再请有能力的人员确认。兼任人员不必提交繁复的内部交接单，可在同一学生记录中切换职责；跨人接手时才记录必要交接。

版本冲突不可静默覆盖。批量采纳不能作为准确率证明，质量抽查需看原作答。排队提示只表示待处理，不把未接单写成已经辅导。

## 5. 校区研判与家长沟通

校区首页优先显示学校作业求助、待核验问题、半月报告待确认、家长反馈与人员负担，不显示“未测学生”“图谱欠账”。共性问题按同一知识范围、题型与帮助条件汇总，列学生数和有效机会分母。

共性研判用于检查题目是否误识别、答疑口径是否清楚、现场支持是否及时以及家长沟通需要；不据此自动组织补课或固定能力分组。坐班人员针对孩子当下学校作业提供帮助，校区向家长解释发现的情况和支持边界。

### 半月报告固定生成

周期为 `Asia/Shanghai` 自然月 1 日至 15 日、16 日至月末，数据窗口左闭右开。报告不依赖小测；样本不足也按期生成，说明实际观察天数、哪些材料有记录、哪些不能判断。首次中途加入标“不足完整周期”。

家长报告包含：

- **学校任务概况**：完成、订正、待核验，列真实分母与任务组成。
- **具体问题**：错误事实与可能原因分开；已核实薄弱范围仅写有依据的子范围。
- **证据卡**：原作业日期、页码题号、错误步骤、帮助条件、同类频次/分母、可信程度和反证。
- **现场帮助**：坐班老师针对哪道学校题说明了什么，孩子如何继续，仍有什么未确认。
- **自主与负担**：提醒次数或强度、合理求助、实际可观察机会、额外活动是否自愿及时间。
- **最小下一步**：优先在后续学校作业观察同类步骤，家长无需额外布题；持续困难时说明将如何现场支持或与学校沟通。

家长能点回本人代表作业，不能看其他孩子。未核验的 AI 原因推断不作为确定结论推送。更正须保留说明和版本；不能悄悄改掉过去的报告。

## 6. 通用交互与质量要求

- 页面具备资料不足、等待核验、失败、离线、权限不足和版本过期状态，不把空白解释成学生问题。
- 图谱有列表替代、颜色配文字，支持必要字号；语音帮助有文字形式。
- 数字由结构化记录计算，AI 解释但不自行编造正确率、次数和分母。
- 学校任务、可选活动、研究活动严格分开；研究性测验须单独说明和同意，不默认额外负担。
- 消息草稿和发送分开，绑定接收对象、授权、幂等与回执；个人导出和删除有身份核验及执行记录。
- 主指标为学校作业完成质量、自主性/提醒依赖、负担、证据可靠性；不以平台使用时长、题量、图谱变绿量或小测参加率考核孩子。

## 7. 产品验收场景

**场景 A 日常新作业形成证据。** 孩子原题经提示订正，几天后独立完成学校同类新题；系统正确区分帮助条件并更新限定范围，未要求额外测验。

**场景 B 没有小测也有准确报告。** 孩子完成学校任务后选择休息，整期未参与额外练习；半月报告照常说明作业事实、答疑和证据不足，不记零分或欠补测。

**场景 C 错误事实与原因假设分离。** 一道题漏乘只记录具体步骤；没有反复证据和现场核实前，家长看不到“分配律整体薄弱”的确定结论。

**场景 D 兼任与改判。** 同一人员分别记录当前题答疑和任务启动提醒；撤销旧错判后图谱、记忆、待发报告同步更正，原始记录可追溯。

验收必须经过真实数据路径，固定展示文案不能冒充个性化。满足上述场景不等于已经证明提分；界面原型、参考内核与生产能力分别标注。
