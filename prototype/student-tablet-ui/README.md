# 荣耀伴学学生端横屏 UI 原型

这是首期学生端产品雏形，用于评审登录页、首页和个人知识图谱页的交互与视觉方向。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8771 --directory prototype/student-tablet-ui
```

浏览器打开 `http://127.0.0.1:8771/`。

## 页面范围

- 登录页：账号、密码、记住账号和基础校验
- 首页：拍照上传、知识图谱两个首期核心入口，后续能力用占位内容表示
- 个人页：学生知识图谱、学科筛选和知识点详情
- 拍照上传：多选图片的演示弹窗，不连接真实上传服务

当前登录、上传和图谱数据均为演示状态，不包含真实账号、后端接口或学生数据。
