# 可运行参考内核

这是用于验证领域规则的本机开发样例。只使用合成学生、4 个课程节点和 7 道示例题，不读取真实学生材料，也不调用模型。它证明若干核心机制可通过程序跑通，不代表整套产品已开发完成。

## 已实现

- 每生不同的 agent_id、知识状态和任务；同一课程结构共享，个人状态独立。
- 作答与老师确认分开；未确认、有帮助、重复原题不计为独立新题证据。
- 规则化图谱、题族覆盖、实际时间间隔、延迟验证与矛盾证据提示。
- 追加复核、纠正或撤销、重新投影，并标记已有计划和报告过期。
- 固定演示身份下的机构、校区、学生范围检查；教官不能做学科复核。
- 幂等重试、同键不同载荷冲突、乐观版本检查。
- 教官观察、支持任务创建、下一课前置检查和课程进度修改。
- 个人计划预算、报告草稿/发布、家长仅查看绑定学生已发布报告。
- 上海时区自然半月窗口函数。

## 运行

在项目根目录执行：

```bash
python3 -m pytest prototype -q
python3 -m prototype.demo
python3 -m uvicorn prototype.api:app --host 127.0.0.1 --port 8787
```

新环境可以在虚拟环境中安装 `prototype/requirements.txt`；版本用于重现本次已安装依赖，不是生产最新版本建议。正式开发需要选择受支持版本并完成依赖检查。当前 Python 3.14 配合本机 FastAPI/Starlette 有弃用提示，功能测试单独列出结果。

访问 `http://127.0.0.1:8787/docs` 可调用参考接口。固定演示身份如下：

| X-Demo-Actor | 可操作范围 |
|---|---|
| teacher-east | 示例机构 east 校区的小林、小雨，学科操作 |
| coach-east | 同校区观察与习惯支持，不能复核 |
| student-lin | 小林本人作答与已授权视图 |
| parent-lin | 小林已发布报告 |
| teacher-west | 同机构 west 校区 |
| teacher-other | 另一机构 |

例如：

```bash
curl -H 'X-Demo-Actor: teacher-east' http://127.0.0.1:8787/v1/students/lin/knowledge-graph
```

`X-Demo-Actor` 是身份选择器，任何本机使用者都能切换，**不构成认证**。不要在公网部署，不接真实数据。服务重启会清空修改并重建合成样本。

## 演示规则和完整产品的区别

规则标识 `demo-rules-v1`：一条独立错误产生待诊断；多条错误可进入需要支持；有独立正确证据进入巩固；最近错误后至少两个日期、至少两个题族且实际间隔至少 24 小时，可进入阶段性较稳。本轮第一次有效独立正确之后至少 7 天的新验证另标延迟已验证。这些都是可调示意门槛，不是普适的教学规律。

知识状态和复习到期分开；新的非独立错误会提示证据矛盾并优先安排检查，而不直接清空此前进步。成功日期数按上海时区统计。报告的知识快照包括截止时间之前的历史证据，周期作答计数使用左闭右开窗口；更正旧判断或补录截止前证据会使相关报告过期，下周期正常新作答不影响历史报告。

参考报告接口允许任意有效分析窗口；正式半月业务应使用 `periods.half_month_window` 生成规范窗口并绑定周期。演示脚本使用该函数。完整的锁卷、缺测补测、双段确认和通知仍在研发清单中。

参考实现采用布尔对错和有限帮助枚举；生产契约还包括部分正确、不可判、未知帮助、步骤证据和多知识点映射。生产正式接口应按 06 文件冻结，不直接照搬演示内部状态字符串。

## 明确尚未完成的工程

没有持久数据库、数据库事务、分布式并发控制、真实身份、对象存储、OCR、模型适配器、完整长期记忆、消息通知、五类前端、完整干预状态流、内容后台或部署恢复系统。内存仓库与本进程锁只便于复现规则，不能替代 PostgreSQL RLS 和生产队列。

`openapi.reference.json` 仅描述已实现的请求结构和路由；返回结构仍由参考实现给出，正式 SDK 需要冻结生产响应 Schema。数据库 DDL 是另行准备的目标结构，内核未连接该数据库。

## 测试重点

测试覆盖隔离、复核权限、待确认不计证据、辅助与原题排除、题族/时间间隔、改判与撤销、幂等冲突、报告过期、预算、日期边界及 HTTP 输入。没有把测试数量解释为产品安全性或教学有效性已证明。
